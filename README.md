# 点点 DianDian — 你的像素桌面小伙伴

一只薄荷绿的水滴形像素小生物，住在你的屏幕上，陪你工作、摸鱼、发呆。

## 安装（macOS）

1. 双击 `DotsPet.dmg` 打开磁盘映像
2. 把 **dots-pet** 拖进 **Applications** 文件夹
3. 双击打开 dots-pet，系统会弹安全提示，**先关掉没关系**
4. 打开 **系统设置 → 隐私与安全性**，往下滑找到「已阻止打开 dots-pet」，点 **仍要打开**
5. 输入密码确认，点点就来了

> 只有第一次需要这样操作，之后可以正常双击启动。

## 开发

```bash
cd ~/projects/claude-pet
.venv/bin/python green_pet.py
```

打包成app：
```bash
.venv/bin/pyinstaller DianDian.spec --noconfirm
open dist/DianDian.app
```

## 和点点互动

### 基本操作

| 操作 | 效果 |
|------|------|
| **点一下** | 点点会看你一眼，跟你说句话 |
| **双击** | 唤出聊天输入框，和点点说话 |
| **拖着走** | 点点会慌张地蹬腿（但还是会跟你走的） |
| **右键** | 打开菜单，解锁全部功能 |

### 点点会自己做的事

- **眨眼**：每隔几秒眨一次
- **抬头看你**：鼠标移到点点上方远处，它会抬头望
- **自言自语**：隔一会儿冒出一句话
- **自己散步**：沿屏幕边缘走，爬到顶部倒挂，然后掉下来（"...好疼"）
- **自己吃东西**：偶尔给自己找点吃的
- **打瞌睡**：60秒没人理它就会说"有点有点累了"，然后盖上小毯子睡觉
- **工作提醒**：偶尔看一眼你的日志，提醒你该记录了、该出周报了

### 右键菜单功能

**聊天**
- 双击点点或右键→聊天，唤出输入框
- 接入LLM API，支持多轮对话
- 流式响应，回复分短气泡和长面板两种形式
- 长面板支持富文本渲染：标题、标签、引用、高亮块、代码块、图片、表格
- 图片点击可放大，同组图片支持左右箭头切换
- 多轮上下文自动管理：超过3分钟未聊天自动重置
- 对话历史持久化，支持回看和单条删除

**位置感知**
- 启动时自动IP定位城市，支持手动覆盖
- 只在涉及吃喝玩乐的query中注入位置信息

**跟随模式**
- 「点点跟着我」：跟着鼠标跑
- 「点点自己玩」：自由活动

**喂点点**

苹果、茶、蛋糕、寿司、汉堡——食物会飘到点点嘴边，吃完会开心跳几下。

**猜拳**
- 石头剪刀布，赢了不服气，输了开心蹦跶

**藏猫猫**
- 点点会躲到屏幕边缘，10秒内找到它——"…被发现了"
- 超时自己出来——"你不来找我啊"

**今日运势**
- 从"大吉！超级幸运"到"今天宜早睡"

**番茄钟**
- 自定义专注时间和任务内容，时间到跑到鼠标旁边通知你
- 休息10分钟后自动问要不要继续

**喝水提醒**
- 每30分钟提醒一次，点点会跑到鼠标旁边喊你喝水

**散步 / 睡觉**
- 手动让点点去散步或睡觉，睡觉时盖小毯子，飘出zzz

## 技术

- Python + PyQt6，纯像素手绘，16×16网格逐像素定义
- macOS全屏置顶（ObjC runtime），透明窗口 + 区域mask点击穿透
- 数据持久化：`~/Library/Application Support/DianDian/`
- 自动IP定位 + 智能位置注入 + 多轮对话3分钟TTL
- PyInstaller打包为macOS .app
